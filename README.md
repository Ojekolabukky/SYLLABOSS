# SYLLABOSS Web Application MVP 

Project Goal

Build a scalable web application that makes it easier for parents in the diaspora to find, select, and access tutors while creating a structured digital workflow for tutor onboarding, matching, scheduling, and live sessions.

Problem We Are Solving

Syllaboss currently relies heavily on manual processes, including WhatsApp, for tutor onboarding, matching, scheduling, and session management. 

This makes the process difficult to scale and creates operational inefficiencies.

Primary Users

Parents in the diaspora
Individuals
Tutors

Expected Deliverable

A functional web application MVP supporting:

Parent onboarding
Onboarding flow for individuals who are not parents 
Tutor onboarding
Tutor matching
Live tutoring sessions
Payment integration
Core parent and tutor functionality.
